# الموقع الرسمي لناصر بوطيب

هذه النسخة مخصصة لعرض الفتاوى المنقولة والبحوث والمقالات التي يضيفها مدير الموقع بنفسه. لا تحتوي على نموذج لاستقبال أسئلة الزوار؛ ويمكن إضافة هذه الميزة مستقبلًا إذا رغبت.

## رفع الموقع من الهاتف إلى GitHub Pages
1. افتح github.com من المتصفح وفعّل «موقع سطح المكتب»، ثم سجّل الدخول.
2. أنشئ مستودعًا جديدًا، ثم ارفع ملفات هذه الحزمة بعد فك الضغط.
3. من Settings ثم Pages اختر Deploy from a branch، والفرع main والمجلد root، ثم Save.
4. بعد النشر سيظهر رابط الموقع في صفحة Pages.

## ربط قاعدة البيانات (Supabase)
1. أنشئ مشروعًا في Supabase ثم افتح SQL Editor ونفّذ محتوى `supabase-schema.sql`.
2. من Authentication > Users أنشئ حساب الإدارة وانسخ UUID الخاص به.
3. في SQL Editor نفّذ الأمر الموجود في آخر `supabase-schema.sql` بعد استبدال النص بالـ UUID الحقيقي.
4. في `config.js` ضع Project URL و anon/publishable key فقط.
5. افتح `admin.html` وسجّل الدخول، ثم جرّب إنشاء مقال كمسودة، وتعديله، ثم نشره.
6. افتح الموقع في نافذة أخرى وتأكد أن المقال المنشور ظاهر وأن المسودة غير ظاهرة للزوار.

## صلاحيات قاعدة البيانات
- الزوار يستطيعون قراءة المقالات المنشورة فقط.
- حساب الإدارة الذي أُضيف إلى جدول `admin_users` يستطيع إنشاء المقالات وتعديلها وحذفها وإدارة المسودات.
- لا تضع مفتاح `service_role` في ملفات الموقع العامة.
